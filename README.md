# Website Profil Mahasiswa
## Penjelasan Singkat
Website yang saya buat ini merupakan website profil pribadi yang dibuat untuk menampilkan informasi mengenai diri saya sebagai mahasiswa Teknologi Informasi. 
Website ini punya beberapa bagian utama yaitu, About, Skills, Portfolio, dan Contact. Website ini dibuat menggunakan HTML untuk struktur halamannya, CSS untuk mengatus tampilan dan responsive design, serta JavaScript untuk menambahkan interaksi dan animasi pada halaman
